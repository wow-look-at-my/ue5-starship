# ue5-starship
Claude Design System for them UE5 Editor theme "Starship"

- `design-system/` holds the design system "UE5.5 Editor UI (Starship)": `tokens.json`, a usage README, component folders (each with a README and a live `preview.html`) and the viewport placeholder. Values come from the UE 5.5.3 Slate source, with file and line citations in each component README.
- `notes/` holds the constants tables behind each component group, including what can not be found.
- The Starship SVG icons are not in the source tree used here, so every icon in the previews is a hand-drawn stand-in.
